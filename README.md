# 🤖 ROS2 Mastery

> "What if learning ROS2 felt more like Duolingo, Brilliant, and a robotics simulator combined?"

An interactive, visual-first learning platform designed to teach ROS2 Humble through exploration, simulations, and active learning.

Instead of memorizing commands from documentation, learners build an intuition for how modern robotic systems communicate, think, and navigate.

## 🌐 Live Demo

https://ros2-mastery.vercel.app

## 🎯 Teaching Philosophy

ROS2 Mastery is built on a simple belief:

> Robotics is too visual and interconnected to be taught through walls of text.

Every lesson follows the same learning pattern:

- Curiosity before definitions
- Visual intuition before implementation
- Interaction before explanation
- Practice before memorization

Our goal isn't to teach ROS2 commands.

Our goal is to help learners think like robotics engineers.

---

## 🚀 Why ROS2 Mastery?

The official ROS2 documentation is excellent—but it was never designed to teach beginners.

Topics like TF2, Nav2, Lifecycle Nodes, and Sensor Fusion become overwhelming when presented as static text.

ROS2 Mastery transforms ROS2 into an interactive experience where learners can:

- Explore system architecture visually.
- Build code progressively.
- Experiment safely in simulated environments.
- Understand why concepts exist before learning how they work.

## ✨ Interactive Features

| Component | Description |
|----------|----------|
| `InteractiveGraph` | Explore Nodes, Topics, TF Trees, and Nav2 pipelines visually. |
| `StepByStepCode` | Reveal complex code incrementally instead of reading large files. |
| `SimulatedTerminal` | Execute common ROS2 commands inside a mock terminal environment. |
| `ComparisonSlider` | Compare architectural concepts side by side. |
| `CalloutPitfall` | Learn the most common ROS2 mistakes before making them. |
| `ConceptCheck` | Short interactive questions throughout the lessons. |
| `ProgressTracker` | Track learning progress across all phases. |

## 🛠️ Running Locally

Clone the repository:

```bash
git clone https://github.com/Ammar-Y206/ros2-mastery.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
